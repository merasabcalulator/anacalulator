# Kuwait UNO Facebook Community Website

## Project Overview
This is a complete website for the Kuwait UNO Facebook page community, featuring a modern, responsive design with interactive elements, authentication system, and multiple playable mini-games.

## Key Features
- **Responsive Design**: Mobile-first approach with modern CSS Grid and Flexbox
- **Authentication System**: Login and registration with Email, Google, and Facebook options
- **Mini-Games Collection**: 7 different playable games including UNO, Memory, Color Match, Number Guessing, Reaction Time, Snake, and Tetris
- **Facebook Integration**: Ready-to-connect social media links and community features
- **Smooth Animations**: CSS animations and JavaScript interactions for enhanced UX
- **Local Storage**: Saves best scores and user login state across browser sessions

## Game Collection
1. **UNO Demo**: Interactive card game with color matching and special cards
2. **Memory Cards**: Flip and match pairs of emoji cards
3. **Color Matching**: Quick reflexes game to match colors
4. **Number Guessing**: Classic guessing game with hints and score tracking
5. **Reaction Time Test**: Measure and improve reaction speed
6. **Snake Game**: Classic arcade game with arrow key controls
7. **Tetris**: Block-stacking puzzle game with line clearing mechanics

## Technical Architecture
- **Single Page Application**: All content in index.html with internal CSS and JavaScript
- **Modular JavaScript**: Each game has its own functions and state management
- **Modern CSS**: Custom properties, Grid layouts, Flexbox, and animations
- **Local Storage Integration**: Persistent best scores, user preferences, and authentication state
- **Authentication System**: Frontend implementation with OAuth providers (Google, Facebook) and email/password
- **Modal System**: Reusable modal components for authentication
- **User Profile Management**: UI components for logged-in state and user profile

## Function Examples

### Basic Game Function Pattern
```javascript
// Game state variables
let gameActive = false;
let gameScore = 0;

// Initialize game
function startGame() {
    gameActive = true;
    gameScore = 0;
    updateDisplay();
}

// Update UI
function updateDisplay() {
    document.getElementById('score').textContent = gameScore;
}

// Handle user input
function handleUserAction(action) {
    if (!gameActive) return;
    
    // Process action
    gameScore += 10;
    updateDisplay();
    
    // Check win condition
    if (gameScore >= 100) {
        endGame();
    }
}

// End game
function endGame() {
    gameActive = false;
    alert(`Game Over! Score: ${gameScore}`);
}
```

### Authentication System Functions
```javascript
// User Authentication State Management
let currentUser = null;

// Check if user is already logged in from localStorage
function checkUserLoginStatus() {
    const savedUser = localStorage.getItem('kuwaitunoUser');
    if (savedUser) {
        currentUser = JSON.parse(savedUser);
        updateUIForLoggedInUser();
    }
}

// Update UI based on login status
function updateUIForLoggedInUser() {
    if (currentUser) {
        // Hide login/register buttons
        document.querySelector('.auth-buttons').style.display = 'none';
        
        // Show user profile
        const userProfile = document.getElementById('userProfile');
        userProfile.classList.add('active');
        
        // Set user avatar and name
        document.getElementById('userAvatar').textContent = currentUser.name.charAt(0).toUpperCase();
        document.getElementById('userName').textContent = currentUser.name;
    } else {
        // Show login/register buttons
        document.querySelector('.auth-buttons').style.display = 'flex';
        
        // Hide user profile
        document.getElementById('userProfile').classList.remove('active');
    }
}

// Login user (email, Google, or Facebook)
function loginUser(user) {
    currentUser = user;
    localStorage.setItem('kuwaitunoUser', JSON.stringify(user));
    updateUIForLoggedInUser();
}
```

## Backend Authentication Integration

For complete authentication functionality with Gmail, Facebook, and email linked to the same user account, a backend service is required. The recommended approach is:

### Supabase Integration
1. **Enable Supabase MCP Tool** in conversation settings
2. **Configure Authentication Providers**:
   - Email/password authentication
   - Google OAuth provider
   - Facebook OAuth provider
3. **Link Authentication Methods** to the same user account
4. **User Profile Management** with connected accounts
5. **Security Rules** for proper data access

### Benefits of Backend Authentication
- **Secure OAuth Flow**: Proper security for authentication tokens
- **Account Linking**: Connect multiple login methods to one account
- **Server-side Validation**: Prevent client-side tampering
- **Cross-device Login**: Consistent user experience across devices
- **User Management**: Admin controls for user accounts
